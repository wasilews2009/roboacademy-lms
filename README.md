# Академія робототехніки ПУЕТ — система адміністрування

Односторінковий застосунок (`index.html`) для обліку учнів, груп, розкладу, відвідування, оцінок, оплат і зарплат.
Дані зберігаються у Firebase (Cloud Firestore), вхід — через Firebase Authentication (пошта й пароль).

- Сайт: https://wasilews2009.github.io/roboacademy-lms/
- Консоль Firebase: https://console.firebase.google.com/project/roboacademy-puet

## Як це влаштовано

- На адресі `*.github.io` система працює з хмарною базою, спільною для всіх пристроїв.
- В інших місцях (або з `?local` в адресі) вона працює як локальне демо в браузері.
- Адміністратори визначаються за поштою: список `OWNER_EMAILS` в `index.html` і такий самий у `firestore.rules`.
- Облікові записи вчителів створює адміністратор у розділі «Учителі». Доступ учителя зберігається в колекції `roles`.
- Дані системи лежать у колекції `lms`: один документ на розділ.
- Правила бази (`firestore.rules`) пускають до даних лише адміністратора й учителів з наданим доступом. Виплати зарплати й витрати на бухгалтера змінює лише адміністратор.

## Налаштування (один раз)

1. **Правила доступу.** У Firebase Console відкрийте Firestore Database → Rules. Замініть увесь текст вмістом файлу `firestore.rules` і натисніть Publish.
2. **GitHub Pages.** У репозиторії відкрийте Settings → Pages. Source: Deploy from a branch, Branch: `main`, папка `/ (root)`, Save.
3. **Дозволений домен.** У Firebase Console відкрийте Authentication → Settings → Authorized domains → Add domain і додайте `wasilews2009.github.io`.
4. **Перший вхід.** Відкрийте сайт і увійдіть поштою адміністратора. База порожня, тому система запропонує відновити дані з резервної копії, почати з порожньої бази або завантажити демо-дані.

## Резервні копії

Адміністратор може зберегти копію всіх даних у файл `.json` і відновити з нього: «Резервна копія» в бічному меню.
